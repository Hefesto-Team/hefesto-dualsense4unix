# Só que a primeira porta pede um COMMIT de foto como prova de um GESTO. Quando
# o gesto não produz bytes — mudou-se código de tela e nenhuma imagem mudou —
# não há o que commitar, e o portão fica vermelho para sempre. Este arquivo é a
# saída, e ela não afrouxa nada:
#
#     rodou o retratista e as imagens MUDARAM   -> commite as imagens
#     rodou o retratista e nada mudou           -> declare aqui o commit
#
# Uma linha por conferência. O primeiro campo é o SHA COMPLETO (40) do commit de
# tela conferido; o resto da linha é para quem for auditar. `#` é comentário.
# A declaração envelhece sozinha: qualquer mexida nova na tela gera outro SHA,
# nenhuma linha daqui o nomeia, e o portão reabre.
#
